# «Мечта» — апартаменты у моря

> Главная страница — основная версия сайта: виртуальная прогулка, модель управления, калькулятор, подбор и частые вопросы. Предыдущие версии лежат в папках [`v2/`](v2/) (с прогулкой, без новых блоков) и [`mechta-v1/`](mechta-v1/) (первая). Разбор сайтов конкурентов — в файле [`ANALIZ.md`](ANALIZ.md).

Сайт апарт-отеля «Мечта» в Феодосии, сделанный по инвестиционной презентации. Чистый HTML, CSS и JavaScript, без сборки и зависимостей.

## Структура

- `index.html` — все разделы и тексты
- `style.css` — стили
- `script.js` — интерактив и **контакты отдела продаж** (объект `CONTACTS` в начале файла)
- `images/` — визуализации, планы и логотип из презентации

## Что нужно заполнить

Откройте `script.js` и впишите контакты в `CONTACTS`: телефон, Telegram и e-mail. Они сразу появятся в блоке контактов, а форма начнёт отправлять заявки в Telegram или на почту.

## Интерактив

- **Виртуальная прогулка на главном экране.** При прокрутке «камера» идёт от фасада здания через террасу и вход в лобби, коридор и апартамент, а затем во двор к бассейну. На предметах стоят точки «+» с подписями, справа список мест для быстрого перехода. Сцены и подписи настраиваются в массиве `TOUR` в `script.js`
- Шапка, которая меняет цвет при прокрутке
- Счётчики цифр
- Фото проявляются при прокрутке и слегка двигаются (параллакс)
- Галерея интерьеров с полноэкранным просмотром (стрелки, свайп, Esc)
- Переключение планировок 2–5 этажей
- Линии гор и моря рисуются сами
- Пульсирующая метка на карте
- Переключатель сезонной загрузки
- Форма заявки

## Как опубликовать (GitHub Pages)

1. Репозиторий должен быть публичным (Settings → Change visibility)
2. Settings → Pages → Deploy from a branch → ветка `claude/laughing-goldberg-3e1m31` (или `main` после слияния), папка `/ (root)`
3. Через 1–2 минуты сайт будет доступен по адресу `https://hamik0977.github.io/Derevenskaypekarnyasite/`
4. Первая версия: `https://hamik0977.github.io/Derevenskaypekarnyasite/mechta-v1/`
